# T.C. Buzdolagı Artıkları Barış Konferansı

> *"Raf adaleti olmadan soğutma olmaz."*  
> — Birinci Olağanüstü Artık Kurultayı, 12 Eylül 2026

Bu depo, buzdolabının orta rafında yıllardır süren soğuk çatışmayı diplomatik usulle sona erdirmek üzere kurulmuş **ulusal öneme haiz** bir yazılımdır.  
Peer-reviewed değildir. Çürüme-reviewed olabilir.

## Ne yapar?

`konferans.py` çalıştığında:

1. Delegasyonu (kuru fasulye, yarım limon, gizemli köfte vs.) salona alır.
2. Rastgele bir başkan seçer.
3. Gerilim çubuğu çizer.
4. Resmi tutanak basar.
5. İşi bitince kapağı kapatır gibi davranır.

## Kurulum

```bash
python3 konferans.py
python3 konferans.py --oturum 42
```

Bağımlılık yoktur. Sadece Python 3 ve bir miktar vicdan yeter.
